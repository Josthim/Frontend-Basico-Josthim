
# Mi página personal - Josthim

## Descripción
Página web personal desarrollada para la asignatura
Diseño de Sistemas en Internet.

## Objetivo
Aplicar los conocimientos básicos de HTML y CSS
para crear una página web organizada y adaptable.

## Contenido
- Presentación personal.
- Lista de intereses y habilidades.
- Imagen de fondo y fotografía de una motocicleta.
- Enlaces a sitios web de interés.
- Menú de navegación.

## Tecnologías utilizadas
- HTML5
- CSS3
